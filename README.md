## 🚀 Featured Projects

### ❄️ [End-to-End Snowflake Data Warehouse & Analytics Pipeline](https://github.com/indra-roi/Snowflake-Data-Warehouse-and-Analytics-Project-)
Medallion Architecture (Bronze → Silver → Gold) integrating ERP and CRM data into one cloud warehouse. Multi-layer SQL pipelines handle cleansing, deduplication and business logic. A Star Schema gold layer feeds Snowsight dashboards for KPIs and revenue trends.

`Snowflake` `SQL` `ELT` `Star Schema` `Snowsight`

### 🏠 Airbnb End-to-End Data Engineering Pipeline
Production-style ELT pipeline: raw booking and listing data in **AWS S3**, modelled with modular **dbt** layers in **Snowflake**. A Star Schema with joins, aggregations and window functions calculates booking revenue and occupancy KPIs.

`Snowflake` `dbt` `AWS S3` `SQL` `Data Modeling`

### 🛒 [Customer Behavior Analysis & Reporting Automation](https://github.com/indra-roi/Retail_Customer_Analysis_Pipeline)
Python + SQL ETL pipeline that cleans and validates **4,000+ customer records** in PostgreSQL (Neon Cloud). Cohort-based segmentation finds high-value customers. Power BI dashboards with DAX cut manual reporting by **40%**.

`Python` `PostgreSQL` `Power BI` `DAX` `ETL`
